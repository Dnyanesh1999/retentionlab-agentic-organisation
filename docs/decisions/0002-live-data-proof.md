# ADR 0002: Live-data proof

Status: accepted

The default assessed path must query Supabase through an MCP tool at the moment the Researcher runs. Stored application artefacts may preserve the result for audit, but they cannot replace the next live query.

The demonstration will edit a fictional Supabase record, run the Researcher again and show the changed value with a new retrieval timestamp and evidence reference. A labelled replay may exist only as a resilience feature and is never assessment evidence for the live connection.
